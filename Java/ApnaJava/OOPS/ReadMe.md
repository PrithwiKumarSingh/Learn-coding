Classes & Object 

Object :- Entities in the real world (ex- pen, tree, bike).
Classes :- Group of these entites. (class is nothing just blueprint of objects).

Construnctor :- Constructor is a special method which is invoked automatically at the time of object creation.

    we create a class define it's properties and we create a constructor with same name of your class name. you don't create a constructor in class then java automatically created a constructor.

    -> Constructors have the same name as class or structure.
    -> Constructors don't have a return type (Not even void). 
    -> Constructors are only called onece, at object creation.
    -> Memory allocation happens when constructor is called.
